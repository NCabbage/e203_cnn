硬件与软件基线

FPGA 板卡
PYNQ-Z2，xc7z020clg400-1
处理器核
Hummingbird E203，RV32IMAC
加速器
4-lane INT8 MAC + Pool + Sobel
总线桥
ICB → AXI-Lite → 寄存器组
下载链路
FTDI JTAG，IDCODE 0x1e200a6d
交互链路
COM9 UART，批量固件 57600 8N1
构建工具
Vivado 2025.2 + Nuclei GCC
不同板卡的引脚、PLL、复位极性、时序和实测周期不能直接复用。A 侧征服者 7020 必须用自己的 bit 与板级约束重新上板。
