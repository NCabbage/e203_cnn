## 二、功能与用法

`CFG1[20] = 1` 进入池化模式：MAC 处由"累加"改为"取最大值"。

```c
CNN_WR(CNN_CFG0, cnn_cfg0(H, W, 1, 2));                  /* C=1, K=2 */
CNN_WR(CNN_CFG1, cnn_cfg1(1, 2, 0, 0, 0) | (1u << 20));  /* POOL=1, S=2, SHIFT=0, RELU=0 */
cnn_load_input(x, H * W);
cnn_run();
```

`cfg_pool = 0` 时行为与原来**完全一致**（回归实测 6 个卷积用例的 cycles 一个没变）。
