## 二、A 侧必须注意（否则会踩同一个坑）

`W_TOTAL_WORDS`、`cnn_regs` 例化参数、`rom_all_tap.hex` **三者要一起更新**，
否则 ROM 会被截断或多读。

更重要的一条 —— **`$readmemh` 的搜索路径**：

```verilog
initial $readmemh("rom_all_tap.hex", w_rom);
```

Vivado 按"当前工作目录 → **RTL 源文件目录**"的顺序找文件。
`reset_run synth_1` 会清空 `synth_1` 目录，所以唯一稳定生效的位置是
**`工程\rtl\cnn\rom_all_tap.hex`**（和 `cnn_top.v` 同目录）。

B 侧首次上板 Sobel 全 0，就是因为只更新了工程根目录和 `synth_1`/`impl_1`，漏了 `rtl\cnn\`，
Vivado 读到了旧的 11060 行文件 → Sobel 段（11060–11065）全 0 → 输出全 0。

综合日志里的

```text
INFO: [Synth 8-3876] $readmem data file 'rom_all_tap.hex' is read successfully
```

**不代表读到了对的文件**，它只说明读到了某个同名文件。务必核对 `rtl\cnn\` 那一份。
