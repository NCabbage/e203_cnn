## 三条硬规则

**1. 共用区改动要通知对方，且不许出现板级信息**

共用区：`rtl/cnn`、`rtl/core`、`rtl/subsys`、`rtl/general`、`rtl/axi_lite_slave`、`python/`、软件工程。
里面不许出现：引脚名、板名、时钟频率常数、按键极性。

**2. 板专属区各留一份，永不互相覆盖**

| 项 | A（AX7020） | B（PYNQ-Z2） |
|---|---|---|
| 顶层复位 | `assign ck_rst = mcu_rst;` | `assign ck_rst = ~mcu_rst;` |
| PL 输入时钟 | H16 = 50 MHz | H16 = 125 MHz |
| 内核时钟 | 16 MHz | 16 MHz |
| 其他 | XDC、PLL `.xci` 各一份 | 同左 |

**3. 实测数据不跨板采信**

- RTL 功能与仿真结论：板无关，可互通
- 上板性能数字（周期、耗时、资源、时序）：**必须各自重测**

## 一次同步的标准流程

1. 改完 → 本地跑通（仿真 + 上板）
2. 在 `sync/` 写一份 `YYYY-MM-DD_<commit>_同步说明.md`，必须包含：
   - 推了什么（文件清单，标出共用 / 板专属）
   - 对方**必须**做什么（改哪一行、要不要重新综合或重编 ELF）
   - 哪些数字**不能**采信（单板口径）
3. `git add` **指定文件**（不要 `git add .`，避免把 `.o/.elf/.map` 等构建产物提交）
4. push，然后通知对方
